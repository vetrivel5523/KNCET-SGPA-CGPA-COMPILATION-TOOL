# KNCET CGPA & SGPA Tool

A user-friendly tool to simplify grade calculations for students. Quickly and accurately calculate CGPA and SGPA, helping you stay focused on your academic goals.

## Features

- **Easy Input**: Enter grades and credits effortlessly.
- **Accurate Calculations**: Ensures precise CGPA and SGPA results.
- **User-Friendly Interface**: Designed for simplicity and ease of use.
- **Real-Time Results**: Instant calculation display.
- **Customizable**: Supports different grading systems.

Achieve academic clarity with ease!
